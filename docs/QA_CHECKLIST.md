# 花生账本 · QA 回归清单

版本基线：0.1.13（versionCode 19）。每次发版至少覆盖“冒烟 + 高风险”两段。

## 1. 冒烟（必过）

- [ ] 全新安装启动为空白账本，无演示采购/销售数据。
- [ ] 应用图标、应用名正确；APK 文件名为 `peanut-ledger.apk`。
- [ ] 新增采购：默认 `供货商1`；保存后进入采购类型选择。
- [ ] 新增称重：单价左、重量右；单价为空聚焦单价，已有单价聚焦重量。
- [ ] 单价回车 → 重量；重量回车 → 保存；金额不被自动聚焦。
- [ ] 新增销售：只能选设置内收购商；保存后自动进入销售类型选择。
- [ ] 隐私模式：销售姓氏框显示序号，标题显示收购商N；金额脱敏。
- [ ] 底部日结卡单击/双击/上拉展开、收起和数字动画正常。
- [ ] 统计默认近7天；切换周期后所有卡片/图表同步。
- [ ] 设置→备份：立即备份成功；备份列表可见。

## 2. 采购 / 销售

### 采购
- [ ] 供应商名称可编辑；回车/保存行为一致。
- [ ] 位置记录关闭时不请求定位；开启时记录并在卡片展示。
- [ ] 添加多个供应商，序号连续（供货商1、2…）。
- [ ] 重命名供应商只影响采购记录。
- [ ] 删除记录后统计/日结同步。

### 销售
- [ ] 新增销售无“现场新增收购商”入口。
- [ ] 销售记录菜单无“重命名收购商”。
- [ ] 设置中重命名收购商，历史销售同步更新；旧销售仍可见。
- [ ] 设置中无收购商时，新增销售提示先去设置添加。
- [ ] 赊账/已结清切换影响赊账统计。

## 3. 称重 / 金额

- [ ] 单价空 → 聚焦单价；上次单价/编辑 → 聚焦重量。
- [ ] 单价回车到重量，重量回车保存；不聚焦金额。
- [ ] 金额自动计算 = 单价 × 重量，两位小数。
- [ ] 手动金额显示“已修改”和差额。
- [ ] 手动价格显示原价划线；改回原价恢复自动。
- [ ] 实付/实收取整、恢复原价、差额正确。
- [ ] 重量 0 保存不产生记录。
- [ ] 空类型自动清理。

## 4. 隐私 / 显示

- [ ] 隐私模式隐藏全部金额、备注/位置等敏感信息。
- [ ] 销售隐私模式不暴露真实收购商名称（包括卡片、菜单、删除确认）。
- [ ] 双击/长按临时显示金额，不泄露销售名称。
- [ ] 标准/大/特大字体下无遮挡、截断可接受。
- [ ] 九套主题可切换并立即生效，重启保留。
- [ ] 日结卡展开/收起状态在切日/切 tab 后重置。

## 5. 统计

- [ ] 近7天/近30天/近1年/自定义日期选择正确。
- [ ] 概览、赊账、排行、图表跟随周期。
- [ ] 斤数/均价独立筛选互不影响。
- [ ] 长按图表显示详情；按住左右移动切换日期。
- [ ] 赊账统计显示未结清总额、比例、欠款排行及最长账龄。
- [ ] 往来排行只含商品收购商。
- [ ] 隐私模式下统计入口受保护。

## 6. 备份 / 恢复

- [ ] 无备份时可调整频率/保留时长（立即刷新）。
- [ ] 手动备份生成 JSON；列表出现记录。
- [ ] 频率/保留自定义弹窗数值校验（1–365 / 1–3650）。
- [ ] 分页每页 5 条，上一页/下一页正确；删除后页码修正。
- [ ] 单条删除/清空全部有确认，不影响当前账本。
- [ ] 导出文件可在系统下载目录找到。
- [ ] 上传备份后进入恢复确认；恢复前创建安全备份。
- [ ] 备份版本高于 APP 时阻断并显示两个版本号。
- [ ] 备份文件 schema/字段为 v1 新字典。

## 7. 日历 / 导航

- [ ] 前后一天、回到今天、左右滑动切页正常。
- [ ] 日历日/月/年视图切换、红点赊账标记。
- [ ] 更多/设置/统计/备份返回路径正确。
- [ ] 硬件返回键不产生空白页。

## 8. 自动化

```bash
./gradlew testDebugUnitTest --offline --console=plain
```

当前覆盖：供应商序号生成、旧自动名称识别、partyName。UI/备份/统计无自动化，必须手工回归。

## 9. 发布门禁

- 冒烟全过。
- 高风险：新增采购/销售、隐私、统计、备份恢复各至少一次完整链路。
- 无新增崩溃、数据丢失、备份 schema 异常。
- APK 版本、文件名、图标、应用名确认。
