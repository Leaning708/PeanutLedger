# 花生账本 · 后续路线图

> 基线：0.1.13（versionCode 19），预发布。以下按优先级而非承诺时间排列。

## 1. 当前状态

- 采购/销售双账本、称重、实付调整、隐私、统计、备份/恢复、设置已完成。
- 新安装空白账本，无 onboarding/演示数据。
- 数据 schema v1；无旧版本兼容层。
- Debug APK 可构建；release 签名/CI 未配置。

## 2. P0：发布硬化（下一阶段优先）

| 事项 | 说明 | 验收 |
| --- | --- | --- |
| Release 签名 | 配置 keystore、signingConfig、正式 APK | 可安装升级、签名校验通过 |
| CI | assemble + unit test + lint | 每次 push 自动跑 |
| 崩溃/错误采集 | 本地日志或可选崩溃上报（若引入网络需产品确认） | 关键崩溃可定位 |
| 备份可靠性 | 验证大小/权限/失败提示 | 100+ 备份分页/清理正常 |
| 大字体回归 | 标准/大/特大全页面 | 无关键遮挡 |
| 数据备份加密 | 可选密码/系统密钥 | 备份文件不可明文读取 |

## 3. P1：数据层与性能

| 事项 | 说明 |
| --- | --- |
| Room/SQLite | 替换全量 JSON；按天/条目增量写入 |
| 异步持久化 | persist 移出主线程，串行化写入 |
| 备份异步化 | 备份/列表/清理移出主线程 |
| 统计预聚合 | 大数据量下按日/月缓存 |
| 结构化迁移 | schema 版本 + 显式 migration，不再“直接破坏” |
| 自动化测试 | Repository、备份版本、统计区间、IME/表单 UI 测试 |

## 4. P2：产品能力

- 账户体系与云同步（多设备、冲突解决、端到端加密）。
- 收购商/供货商档案（联系方式、历史价格、欠款汇总）。
- 价格趋势、按类型/收购商的历史对比。
- CSV/Excel 导出、打印对账单。
- 备份文件用户可见目录/分享（SAF 已支持下载，可继续增强）。
- 多语言/英文。

## 5. P3：体验与可访问性

- 深色模式/跟随系统。
- 无障碍标签、TalkBack 流程、焦点顺序。
- 动效降级/减少动画。
- 更完整的空态、错误态、加载态。
- 截图自动化与视觉回归。

## 6. 技术债清单

1. `LedgerState` 单体过大，拆分控制器。
2. 同步 JSON/备份 IO。
3. 仅 1 个 JVM 单测；无 UI/备份自动化。
4. 无 release 签名/CI/崩溃采集。
5. 备份在应用目录，卸载/清数据即丢失。
6. 统计图表/日期选择器高度定制，后续改动缺少视觉回归。
7. schema v1 无兼容层，发布后必须建立迁移规范。

## 7. 风险

- **数据丢失**：本地 JSON 损坏、备份目录被清除、卸载。
- **规模**：全量 JSON 写入随记录数增长变慢。
- **口径**：收购商改名/失效、赊账账龄、统计周期边界。
- **发布**：无签名/CI 时人工发版易出错。
