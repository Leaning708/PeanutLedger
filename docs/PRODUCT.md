# 花生账本 · 产品说明

## 1. 产品定位

花生账本是一款**纯本地、离线可用**的 Android 记账工具，面向花生收购/销售场景，覆盖采购、销售、称重、赊账、统计和本地备份。

- 无需登录，无服务端，无网络请求。
- 数据保存在设备本地；备份文件保存在应用目录。
- 目标用户：需要按天、按供货商/收购商记录重量、单价、金额和结算状态的个人或小商户。

## 2. 术语表

| 中文 | 代码/数据字段 | 含义 |
| --- | --- | --- |
| 采购 | `PURCHASE` / `purchases` | 向供货商采购花生 |
| 销售 | `SALE` / `sales` | 向收购商销售 |
| 供货商 | `supplierName` | 采购记录的卖方 |
| 收购商 | `buyerName` / `buyers` | 销售记录的买方 |
| 类型 | `LedgerType` | 花生果、商品米等品类 |
| 称重 | `LedgerItem` | 一条重量 + 单价记录 |
| 赊账 | `settled = false` | 销售尚未结清 |
| 实付/实收 | `entryFinal` | 记录最终金额（含调整） |
| 账龄 | `oldestDays` | 未结清销售距今天数 |

## 4. 功能与业务规则

### 4.1 采购

- 新增采购的供货商名称默认 `供货商N`，按当天序号生成，输入框可改成真实名称。
- 新增采购保存后自动进入采购类型选择。
- 采购记录卡片姓氏框显示序号；是否显示真实名称以名称为准。
- 支持位置记录：新增采购时读取位置，条目上展示；隐私模式下不显示位置。
- 采购类型、称重明细和实付金额均可编辑；记录可重命名/删除。

### 4.2 销售

- 新增销售必须从**设置中的收购商列表**选择，不能在销售页现场新增或改名。
- 收购商改名只能在设置中完成，历史销售同步更新。
- 保存销售后自动进入销售类型选择。
- 销售隐私模式下：
  - 姓氏框显示当天序号（1、2…）。
  - 标题显示 `收购商1`、`收购商2`…，不暴露真实名称。
  - 金额与实收按隐私逻辑脱敏。
- 支持赊账/已结清切换；默认结算状态在设置中配置。
- 未结清销售进入赊账统计和欠款排行，展示最长账龄。

### 4.3 称重与金额

- 字段顺序固定：**单价在左、重量在右**。
- 单价为空时聚焦单价；单价已有值（上次单价/编辑场景）时聚焦重量。
- 键盘动作：单价回车 → 重量；重量回车 → 保存；金额输入框不会自动聚焦。
- 金额默认 = 单价 × 重量，保留两位小数；可手动覆盖。
- 手动价格会在条目上以原价划线；手动金额显示差额。
- 重量 ≤ 0 不产生记录。
- 实付/实收支持向上取整和恢复原价。

### 4.4 统计

- 顶部周期：近7天、近30天、近1年、自定义起止日期。
- 所有统计卡片和线条图跟随周期；默认近7天。
- 斤数/均价图各自独立类型筛选；图例与线条高对比配色。
- 折线图长按显示详情，按住左右移动自动切换日期。
- 赊账统计：当前周期未结清总额、占周期销售比例、欠款排行；每位收购商显示最长账龄。
- 往来排行只展示商品收购商，按周期销售额排序。

### 4.5 隐私模式

- 一键隐藏所有金额；销售隐藏收购商真实名称并显示序号。
- 双击/长按卡片可临时显示金额（销售名称仍按隐私规则隐藏）。
- 新增称重/添加类型时会自动临时显示当前条目并继续操作。

### 4.6 日结卡

- 底部「今日收支」默认收起，只显示收支和采购/销售金额。
- 单击标题、双击或上拉展开；再次单击/双击或下滑收起。
- 展开后合并采购/销售两列，显示金额、斤数、均价、当天赊账金额，单位在值末尾。
- 展开/收起带尺寸动画。

### 4.7 备份与恢复

- 支持手动备份、自动备份、备份列表分页、单条删除、清空、导出、上传恢复。
- 默认每天一次、保留30天；频率可选关闭/每天/每周/每月/自定义；保留可选7/30/365天/自定义。
- 自动备份在 APP 进入后台时触发，每个周期最多一次；跨天仍在使用时检查补备。
- 恢复前提示覆盖全部账本、类型、收购商和设置，并自动创建恢复前安全备份。
- 备份文件包含 APP 版本、versionCode、schema 版本、格式版本；高版本备份会被低版本 APP 阻断。
- 当前 schema 为 **v1，不保留旧 schema 兼容层**（APP 尚未发布）。

### 4.8 设置与显示

- 字体：标准 / 大 / 特大（1.0 / 1.15 / 1.3）。
- 九套主题：松绿（默认）、暖棕、黛蓝、绛紫、青黛、墨灰、海盐、樱粉、琥珀。
- 位置记录开关；关闭后新增采购不请求定位。
- 清空记账数据保留类型/收购商设置。

## 5. 非目标

当前版本明确不包含：

- 登录、账户体系、云同步。
- 首次安装演示采购/销售数据（新安装为空账本）。
- 多语言（当前仅中文）。
- 服务端报表/分享。
- 自动 schema 兼容旧版本。

## 6. 验收基线

- 新安装：空白账本，无演示数据。
- 新增采购/销售全流程可用。
- 单价/重量布局和键盘跳转符合要求。
- 销售只能选择设置中的收购商。
- 统计数据随周期联动且无重复周期文案。
- 备份可创建、分页、导出、上传、恢复；版本过高会阻断。
- 标准/大/特大字体下无关键遮挡。
